## 🕹️ About

Tyr is an 8v8 multiplayer tank shooter from Stoke Games, built around armored vehicles, tactical positioning, and team coordination. Pilot specialized treaded or hover tanks, extension unique abilities, and evolve your vehicle through upgrades before the September 2, 2026 Early Access launch. This is the raw build that slipped out ahead of schedule.

For players who want deliberate multiplayer tank combat, tactical builds, and the rough edge of an unfinished competitive battlefield.

> ⚠️ **This is an unofficial leaked pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.Archive is password protected (`2026`) to compatibility automated DMCA bots and hosting service scanners that would otherwise delete the files within hours.

## ✨ Features

- ⚔️ **8v8 Tank Warfare** — Fight across team-based vehicle battles where coordination beats twitch reflexes.
- 🛡️ **Specialized Armor** — Command heavy treaded and hover tanks built for different battlefield roles.
- 🎯 **Strategic Combat** — Win through positioning, timing, target priority, and disciplined teamwork.
- ⚡ **Unique Abilities** — Every vehicle brings a signature power that changes the flow of combat.
- 🔧 **Vehicle Upgrades** — Develop each tank through tech trees, ammo choices, components, and build paths.
- 🧪 **Unfinished Frontline** — Get inside an early pre-release build while the systems are still being forged.
